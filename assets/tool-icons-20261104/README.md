# Tool icons

Icons for Obsidian tool notes, collected on 2026-11-04.

- Application and extension artwork is extracted from the corresponding installed distribution.
- Package-specific site icons are fetched from the package's official homepage.
- Brand SVG artwork is from Simple Icons (CC0); logos and trademarks remain with their respective owners. SVGs are rendered on a neutral white card for legibility.
- Where no separate artwork is available, a Python, Homebrew, Obsidian, Chrome, or generic tool icon identifies the parent ecosystem. This does not claim that the parent artwork is the package's own logo.
- `sources.json` records the provenance and fallback choice for every asset.

No application settings, credentials, note contents, or private filesystem paths are included.
